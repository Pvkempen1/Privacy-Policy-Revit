1. Data Collection

The Copy with Base Point add-in for Autodesk Revit does not collect, store, transmit, or process any personal data from users.

The add-in also does not collect or transmit Revit project data, model data, user files, object selections, geometry, coordinates, or any other information from the user’s Revit environment.

All operations performed by the add-in take place locally within Autodesk Revit on the user’s computer.

2. Use of Data

Because the add-in does not collect any personal data or project data, no data is used for analytics, advertising, licensing, tracking, marketing, or any other purpose.

3. Data Sharing with Third Parties

The add-in does not share any personal data or project data with third parties.

The add-in does not use third-party analytics tools, advertising networks, tracking tools, external SDKs, or cloud services.

4. Data Retention and Deletion

Because the add-in does not collect or store any personal data or project data, there is no user data retained by the publisher.

As no data is stored, there is no data to delete.

5. User Consent and Revocation

Because the add-in does not collect or process personal data, no separate consent is required for data collection.

Users may stop using the add-in at any time by disabling or uninstalling it from Autodesk Revit.
